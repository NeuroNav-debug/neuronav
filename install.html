Install NeuroNav

Your ADHD companion app — install it on your device for the best experience.

💻 Windows (Chrome/Edge)
Installs as a desktop app with taskbar icon
  1. Open NeuroNav in Chrome or Edge
  2. Look for the ⬇️ Install button at the bottom
  3. Or click ⋮ → Cast, save and share → Install page as app
🍎 macOS (Chrome)
Appears in Applications folder and Dock
  1. Open NeuroNav in Chrome
  2. Click ⋮ → Cast, save and share → Install page as app
  3. Find NeuroNav in your Applications folder
🐧 Linux (Chrome/Edge)
Works on Ubuntu, Fedora, Arch, etc.
  1. Open NeuroNav in Chrome/Edge
  2. Click ⋮ → More tools → Create shortcut
  3. Check "Open as window"
📱 iPhone / iPad
Add to Home Screen for full-screen app experience
  1. Open NeuroNav in Safari
  2. Tap Share button (⬆️)
  3. Scroll down and tap "Add to Home Screen"
🤖 Android
Installs like any app from the Play Store
  1. Open NeuroNav in Chrome
  2. Tap ⋮ → "Add to Home screen" or "Install app"
  3. Tap Install
🚀 Open NeuroNav

NeuroNav is a Progressive Web App (PWA). No app store needed.
Works offline. Updates automatically.
